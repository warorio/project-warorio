# [Project Warorio]

## What this site is
It is a website that pushes environmental conservation

## Who it is for
Youth, because they are the strongest and the most ambitious social groups and tey need this website to improve the environment for future generations.

## How to open it
Live site: https://warorio.github.io/project-warorio/index.html

## What it does
- Three connected pages: Home, About the movement, Educational materials and social center
- A button that shows and hides this week's leaderboard
- A list built from data based on people collecting litter
